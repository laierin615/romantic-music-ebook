# 穿越音符時光機！浪漫樂派大冒險（初期 ＆ 早期篇）

專為國小音樂課設計的互動漫畫電子書網頁。單一 `index.html` 加上 `images/` 資料夾，直接用 GitHub Pages 發布。

線上網址：https://laierin615.github.io/romantic-music-ebook/

## 本冊收錄內容

- **翻頁電子書**：51 頁，撞色卡片版面；按 ◀ ▶、手機左右滑、鍵盤方向鍵都能翻頁，有翻頁動畫和翻紙聲。
- **黑貓老師**：全書的講解角色，會眨眼、搖尾巴，講話時嘴巴會動，對話框逐字出現；按「🔊 念給我聽」用瀏覽器內建語音朗讀。
- **冒險地圖**：8 關，每關依成績拿 1～3 顆星和一張作曲家貼紙，累積音符幣升級稱號（見習小樂手 → 浪漫大師），最後有可列印的結業證書。
- **8 幅章節大插圖**：封面與第 1～7 話主插圖。
- **28 格搞笑四格漫畫**：7 組四格漫畫直接整頁呈現，每格配簡短搞笑對話與 🔊 朗讀，下方附漫畫重點。
- **7 關記憶翻牌遊戲**：每關 6 對「題目卡↔答案卡」（例如 第 5 號交響曲↔命運、羅西尼的生日↔2 月 29 日），記錄翻牌次數與秒數，放在闖關測驗前。
- **19 首鐘琴示範曲（約 13～23 秒）**：用 Web Audio API 即時合成可愛鐘琴主旋律＋木琴低音，不需要音檔；播放時黑貓老師會跟著搖擺。
  - 第 1 關：貝多芬《命運》開頭、莫札特《小星星變奏曲》主題、海頓《驚愕交響曲》第二樂章
  - 第 2 關：莫札特《小夜曲》開頭（古典）、同一段的浪漫改編（示範）
  - 第 3 關：貝多芬《命運》《英雄》《田園》《合唱》、〈給愛麗絲〉、《月光奏鳴曲》
  - 第 4 關：韋伯《魔彈射手》〈獵人合唱〉、《奧伯龍》序曲的魔法號角
  - 第 5 關：羅西尼《威廉泰爾》序曲終段、《塞爾維亞的理髮師》序曲
  - 第 6 關：舒伯特〈鱒魚〉、〈野玫瑰〉、〈搖籃曲〉、《未完成交響曲》第二主題、《冬之旅》〈菩提樹〉
- **86 題闖關測驗**：一次一題，答對有彩帶，答錯黑貓老師會說明；第 1～7 關各 10 題，第 8 關總複習 16 題（含 4 題聽音辨曲）。

## 使用小提醒

- 網址後面加 `#ch3` 直接開到第 3 關，`#ch3-2` 是第 3 關的第 2 頁；`#map` 是冒險地圖。
- 闖關紀錄（星星、音符幣、貼紙）只存在這台裝置的瀏覽器；教室共用電腦可在冒險地圖按「清除這台裝置的闖關紀錄」。
- iPhone／iPad 要先關閉「靜音模式」才聽得到音樂和朗讀。
- 示範音樂是依原曲主題簡化的鐘琴音色，不是原曲錄音。

## 檔案結構

```
index.html      電子書主檔（內容、音樂、測驗都在這裡）
images/         插圖：hero_cover、hero_ch1～7、comic_ch1～7（四格原圖）、comic_chN_1～4（拆好的單格）
README.md       本說明
```

## 發布方式

Settings → Pages → Source 設為 **Deploy from a branch**，Branch 選 **main / (root)**。推送到 main 後約 1～2 分鐘更新。
