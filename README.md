# 穿越音符時光機！浪漫樂派大冒險（初期 ＆ 早期篇）

專為國小音樂課設計的互動漫畫電子書網頁。單一 `index.html` 加上 `images/` 資料夾，直接用 GitHub Pages 發布。

線上網址：https://laierin615.github.io/romantic-music-ebook/

## 本冊收錄內容

- **8 幅章節大插圖**：封面與第 1～7 話主插圖。
- **7 組情境記憶四格漫畫（起・承・轉・合）**：浪漫樂派緣起、風格對比、貝多芬、韋伯、羅西尼、舒伯特、早期四大天王總整理。
- **12 首雙聲部示範音樂（約 16～22 秒）**：用瀏覽器內建的 Web Audio API 即時合成主旋律與低音，不需要任何音檔，可隨時停止並顯示剩餘秒數。
  - 貝多芬：《第五交響曲・命運》開頭、《第九交響曲》〈歡樂頌〉、《第六交響曲・田園》溪邊鳥叫
  - 風格對比：莫札特《小夜曲》開頭（古典）、同一段的浪漫改編（示範）
  - 韋伯：《魔彈射手》〈獵人合唱〉、《奧伯龍》序曲的魔法號角
  - 羅西尼：《威廉泰爾》序曲終段、《塞爾維亞的理髮師》序曲
  - 舒伯特：〈鱒魚〉、〈野玫瑰〉、〈搖籃曲〉
- **86 題互動隨堂測驗**：第 1～7 話每話 10 題（共 70 題），加上第 8 話總複習 16 題（含 4 題聽音辨曲）。作答後立即顯示正解與解析，並統計每話與全冊成績。

## 使用小提醒

- 網址後面加 `#ch3` 可以直接開到第 3 話，其他話依此類推（`#ch1`～`#ch8`）。
- iPhone／iPad 要先關閉「靜音模式」才聽得到示範音樂。
- 示範音樂是依原曲主題簡化的電子音，不是原曲錄音。

## 檔案結構

```
index.html      電子書主檔（內容、音樂、測驗都在這裡）
images/         15 張插圖（hero_cover、hero_ch1～7、comic_ch1～7）
README.md       本說明
```

## 發布方式

Settings → Pages → Source 設為 **Deploy from a branch**，Branch 選 **main / (root)**。推送到 main 後約 1～2 分鐘更新。
